Sent at the start of the game, and after each mulligan, to ask whether the
player keeps the hand. The reference client shows Keep and Mulligan buttons in
the bottom action slot, not a dialog.

![The mulligan prompt in the Manabrew client](/protocol/mulligan.webp)

## Arguments

`input.type` is `"mulligan"`. The remaining fields:

<ProtocolType slug="mulligan" />

:::note[London mulligan]
A player who mulliganed `n` times puts `n` cards back after keeping. That is
a separate prompt, `mulliganPutBack`.
:::

## Response

```ts
type MulliganOutput = { type: "mulliganDecision"; keep: boolean };
```

`keep: true` keeps the hand, `false` draws a new one.

## Example

```json
{
  "promptId": 1,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "mulligan",
    "handCardIds": ["hand-0", "hand-1", "hand-2", "hand-3", "hand-4", "hand-5", "hand-6"],
    "mulliganCount": 1
  }
}
```

```json
{
  "kind": "response",
  "promptId": 1,
  "action": {
    "type": "mulligan",
    "output": {
      "type": "mulliganDecision",
      "keep": true
    }
  }
}
```
