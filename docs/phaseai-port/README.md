# phase-ai → forge-ai faithful-port blueprint

Planning artifacts for adapting [phase-rs/phase `phase-ai`](https://github.com/phase-rs/phase/tree/main/crates/phase-ai)
(Apache-2.0, used with the maintainer's permission) onto manabrew's Rust engine,
implemented in the `forge-ai` crate. Generated by a multi-agent analysis pass.

Start with **[MASTER-PLAN.md](MASTER-PLAN.md)** — the dependency-ordered
implementation layers (L0–L7) and the Faithful / Adapted / Infeasible risk
register.

- `api-*.md` — manabrew engine API maps (state, ability IR, combat/mana, simulation).
- `foundation-sim-hook.md` — why a mid-turn-resume hook is not a minimal change, and
  the `run_until` + `SimUnit` v1 adapter that sidesteps it.
- `foundation-classification.md` — the three-tier effect classifier over manabrew's
  ability IR that unblocks `policies/` + `features/`.
- `spec-*.md` — per-module faithful-port specs (Phase→manabrew API mapping, Rust
  skeletons, verbatim weights/formulas, dependencies, risks).

These are a blueprint, not final code. As of this commit, `forge-ai` contains the
eval foundation (see the PR); the layers above are implemented against these specs.
