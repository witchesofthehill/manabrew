Sent when an effect asks for a color: Painter's Servant, or the color half of
a hybrid payment.

## Response

```ts
type ChooseColorOutput = { type: "colorDecision"; chosenColors: { [color: string]: number } };
```

A map from color to times chosen. The counts sum to `amount`.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "chooseColor",
    "validColors": ["W", "U", "B", "R", "G"],
    "amount": 1,
    "repeatAllowed": false
  }
}
```

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "chooseColor",
    "output": {
      "type": "colorDecision",
      "chosenColors": {
        "R": 1
      }
    }
  }
}
```
