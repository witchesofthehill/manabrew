Sent when the player picks an integer: how many times to replicate, or an X
that is not part of a mana cost.

## Arguments

`input.type` is `"chooseNumber"`. The remaining fields:

## Response

```ts
type ChooseNumberOutput = { type: "numberDecision"; chosenNumber: number | null };
```

The chosen integer in `[min, max]`. `null` only when cancelling is legal and
the player cancelled.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "chooseNumber",
    "presentation": {
      "title": "Replicate",
      "description": "Choose how many times to copy this spell.",
      "text": "Pay {2} for each replicate.",
      "targets": []
    },
    "min": 0,
    "max": 5
  }
}
```

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "chooseNumber",
    "output": {
      "type": "numberDecision",
      "chosenNumber": 3
    }
  }
}
```
