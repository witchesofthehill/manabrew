import ProtocolType from "../../../components/ProtocolType.astro";

Sent for the London mulligan put-back: after keeping, a player who mulliganed
`n` times puts `n` cards from hand on the bottom of the library. The reference
client shows a confirm button in the bottom action slot while the player picks
cards in hand.

![The mulliganPutBack prompt in the Manabrew client](/protocol/mulligan-back.webp)

## Arguments

`input.type` is `"mulliganPutBack"`. The remaining fields:

<ProtocolType slug="mulligan-put-back" />

## Response

```ts
type MulliganPutBackOutput = { type: "mulliganPutBackDecision"; cardIds: string[] };
```

Exactly `count` card ids, the cards to put on the bottom.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "mulliganPutBack",
    "handCardIds": ["hand-0", "hand-1", "hand-2", "hand-3", "hand-4", "hand-5", "hand-6"],
    "cards": [
      { "id": "hand-0", "identity": { "name": "Island" } },
      { "id": "hand-1", "identity": { "name": "Counterspell" } }
    ],
    "count": 1
  }
}
```

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "mulliganPutBack",
    "output": {
      "type": "mulliganPutBackDecision",
      "cardIds": [
        "hand-0"
      ]
    }
  }
}
```
