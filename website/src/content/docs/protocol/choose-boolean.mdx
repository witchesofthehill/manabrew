Sent when the engine needs a yes/no decision from the player - for example,
whether to pay an optional cost such as buyback when casting a spell.

## Arguments

`input.type` is `"chooseBoolean"`. The remaining fields:

<ProtocolType slug="choose-boolean" />

`kind` says what the question is: an optional trigger, a replacement effect
(dredge, miracle), a static effect, a payment to confirm, a cost to pay to stop
an effect, a coin flip, and so on. `detail` and `api` carry the engine's own
tags for the question and the effect behind it (on Forge, its confirm mode or
cost part, and the ability's `ApiType`). All three are optional.

## Response

```ts
type ChooseBooleanOutput = { type: "decision"; value: boolean };
```

Return `true` to accept and `false` to decline.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "chooseBoolean",
    "presentation": {
      "title": "Buyback",
      "description": "Pay {3} more to return this spell to your hand as it resolves?",
      "targets": []
    },
    "confirmLabel": "Pay",
    "denyLabel": "Decline"
  }
}
```

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "chooseBoolean",
    "output": {
      "type": "decision",
      "value": true
    }
  }
}
```
