Sent for a yes/no decision, such as whether to pay buyback.

## Arguments

## Response

```ts
type ChooseBooleanOutput = { type: "decision"; value: boolean };
```

`true` accepts, `false` declines.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "chooseBoolean",
    "presentation": {
      "title": "Buyback",
      "description": "Pay {3} more to return this spell to your hand as it resolves?",
      "targets": []
    },
    "confirmLabel": "Pay",
    "denyLabel": "Decline"
  }
}
```

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "chooseBoolean",
    "output": {
      "type": "decision",
      "value": true
    }
  }
}
```
