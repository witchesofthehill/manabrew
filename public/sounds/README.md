# Bundled presentation audio

These effects form a restrained tabletop palette: physical cards, wooden pieces, page turns, dice, coins, and a small set of fantasy accents. All source recordings are dedicated to the public domain under [Creative Commons Zero 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Source and license pages were checked on 2026-09-10.
