import ProtocolType from "../../../components/ProtocolType.astro";

Sent in the declare-attackers step. The engine lists which creatures can
attack and which players, planeswalkers or battles each one can attack.

![The chooseAttackers prompt in the Manabrew client](/protocol/declare-attackers.webp)

## Arguments

`input.type` is `"chooseAttackers"`. The remaining fields:

<ProtocolType slug="choose-attackers" />

## Response

```ts
type ChooseAttackersOutput = { type: "declareAttackers"; assignments: AttackAssignment[] };
type AttackAssignment = { attackerId: string; targetId: string };
```

One `AttackAssignment` per attacker, one creature at one target. Creatures
that stay home are left out.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "chooseAttackers",
    "attackers": [
      { "attackerId": "bf-3", "validTargetIds": ["player-1", "pw-1"] },
      { "attackerId": "bf-4", "validTargetIds": ["player-1", "pw-1"] }
    ],
    "attackTargets": [
      { "id": "player-1", "label": "Opponent", "kind": "player" },
      { "id": "pw-1", "label": "Jace, the Mind Sculptor", "kind": "planeswalker" }
    ]
  }
}
```

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "chooseAttackers",
    "output": {
      "type": "declareAttackers",
      "assignments": [
        {
          "attackerId": "bf-3",
          "targetId": "player-1"
        },
        {
          "attackerId": "bf-4",
          "targetId": "pw-1"
        }
      ]
    }
  }
}
```
