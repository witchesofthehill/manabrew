Types used by more than one prompt. The prompt pages link here.

## PromptPresentation

The title and description most modal prompts open with. The client uses it to
show which card or effect caused the prompt.

<ProtocolType type="PromptPresentation" />

## TargetRef

A reference to a player, card or spell. `intent` and `oracle` are hints the
UI may use to annotate the target.

<ProtocolType type="TargetRef" />

## TargetKind

Which id space a [`TargetRef`](#targetref) points into: player, card, or
spell on the stack.

<ProtocolType type="TargetKind" />

## ScryDestination

A zone a [scry](/protocol/scry/) prompt can send a card to.

<ProtocolType type="ScryDestination" />

## DiceRollEntry

One player's dice result.

<ProtocolType type="DiceRollEntry" />

## AvailableAction

One legal action in [chooseAction](/protocol/choose-action/): cast a spell,
activate an ability, or undo a mana activation.

<ProtocolType type="AvailableAction" />

## ActivatableAbilityInfo

A mana ability the player can activate while paying a cost
([payManaCost](/protocol/pay-mana-cost/)).

<ProtocolType type="ActivatableAbilityInfo" />

## AttackerOptionDto

A creature that can attack, with the set of targets it may attack
([chooseAttackers](/protocol/choose-attackers/)).

<ProtocolType type="AttackerOptionDto" />

## AttackTargetDto

What an attacker can attack: a player, planeswalker or battle.

<ProtocolType type="AttackTargetDto" />

## AttackTargetKind

Which kind of thing an [AttackTargetDto](#attacktargetdto) is.

<ProtocolType type="AttackTargetKind" />

## BlockableAttackerDto

An incoming attacker and how it may be blocked
([chooseBlockers](/protocol/choose-blockers/)).

<ProtocolType type="BlockableAttackerDto" />

## TokenScript

Forge's token script name, an opaque string on the wire. It tells apart tokens
with the same name and different rules, such as `w_2_2_knight_vigilance` and
`w_2_2_knight_flying`. The definitions are in Forge's
[`tokenscripts`](https://github.com/Card-Forge/forge/tree/master/forge-gui/res/tokenscripts)
directory.

<ProtocolType type="TokenScript" />
