Sent for effects that sort cards into zones. Scry, Surveil and Fateseal all
use it. The player puts each card in one of the allowed destinations.

## Arguments

`input.type` is `"scry"`. The remaining fields:

<ProtocolType slug="scry" />

```ts
type ScryDestination = "libraryTop" | "libraryBottom" | "graveyard" | "exile" | "hand";
```

## Response

```ts
type ScryOutput = { type: "scryDecision"; zoneCardIds: string[][] };
```

`zoneCardIds` is parallel to `zones`: one array of card `id`s per zone, in
final order. Every card in `cards` appears in exactly one array.

## Example

A two-card Scry, keeping one on top and binning the other:

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "scry",
    "presentation": { "title": "Scry 2", "targets": [] },
    "cards": [
      { "id": "lib-0", "identity": { "name": "Island" } },
      { "id": "lib-1", "identity": { "name": "Counterspell" } }
    ],
    "zones": ["libraryTop", "libraryBottom"]
  }
}
```

`zoneCardIds[0]` is `"libraryTop"`, `zoneCardIds[1]` is `"libraryBottom"`:

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "scry",
    "output": {
      "type": "scryDecision",
      "zoneCardIds": [
        [
          "lib-1"
        ],
        [
          "lib-0"
        ]
      ]
    }
  }
}
```
