---
title: "gameOver"
description: Notify the client that the game has ended; no response is expected.
---

import ProtocolType from "../../../components/ProtocolType.astro";

Sent when the game has ended: a win, a loss, or a draw. It is the last
prompt. The client takes down the board and shows the result.

## Arguments

`input.type` is `"gameOver"`. There are no other fields.

<ProtocolType slug="game-over" />

## Response

None.

## Example

```json
{
  "promptId": 42,
  "decidingPlayerId": "player-0",
  "input": { "type": "gameOver" }
}
```
