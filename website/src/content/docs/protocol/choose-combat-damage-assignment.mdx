---
title: "chooseCombatDamageAssignment"
description: Ask the attacking player how to split a creature's combat damage among its blockers.
---

import ProtocolType from "../../../components/ProtocolType.astro";

Sent when an attacker's damage is split among its blockers, and the defender
too if it has trample. A 4/4 trampler blocked by a 2/2 can put 2 on the
blocker and 2 on the player.

## Arguments

`input.type` is `"chooseCombatDamageAssignment"`. The remaining fields:

<ProtocolType slug="choose-combat-damage-assignment" />

## Response

```ts
type ChooseCombatDamageAssignmentOutput = {
  type: "combatDamageAssignmentDecision";
  assignments: CombatDamageAssignmentEntry[];
};
type CombatDamageAssignmentEntry = { assigneeId: string; damage: number };
```

One entry per assignee: each blocker, and `defenderId` if damage tramples
over. The `damage` values sum to `totalDamage`. With `attackerHasDeathtouch`,
1 damage is lethal, so 1 per blocker is enough before moving on.

## Example

```json
{
  "promptId": 13,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "chooseCombatDamageAssignment",
    "attackerId": "bf-3",
    "blockerIds": ["bf-7"],
    "defenderId": "player-1",
    "totalDamage": 4,
    "attackerHasDeathtouch": false
  }
}
```

```json
{
  "kind": "response",
  "promptId": 13,
  "action": {
    "type": "chooseCombatDamageAssignment",
    "output": {
      "type": "combatDamageAssignmentDecision",
      "assignments": [
        {
          "assigneeId": "bf-7",
          "damage": 2
        },
        {
          "assigneeId": "player-1",
          "damage": 2
        }
      ]
    }
  }
}
```
