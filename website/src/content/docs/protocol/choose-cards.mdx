Sent when the player picks cards from a set: discard to hand size, choose
what to sacrifice, pick from a revealed pile. The cards come inline, so the
client does not need the game state to draw them.

## Arguments

`input.type` is `"chooseCards"`. The remaining fields:

## Rendering

The layout depends on how many cards there are. Both send the same
`chooseCardsDecision`. The footer shows selected / `max` and a confirm once
the count is between `min` and `max`.

## Response

```ts
type ChooseCardsOutput = { type: "chooseCardsDecision"; chosenCardIds: string[] };
```

The `id`s of the chosen cards, between `min` and `max` of them.

## Example

```json
{
  "promptId": 12,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "chooseCards",
    "presentation": { "title": "Discard two cards", "targets": [] },
    "cards": [
      {
        "id": "hand-0",
        "identity": { "name": "Lightning Bolt" },
        "manaCost": "{R}",
        "types": ["Instant"]
      },
      {
        "id": "hand-1",
        "identity": { "name": "Llanowar Elves" },
        "manaCost": "{G}",
        "types": ["Creature"],
        "power": "1",
        "toughness": "1"
      }
    ],
    "min": 2,
    "max": 2
  }
}
```

```json
{
  "kind": "response",
  "promptId": 12,
  "action": {
    "type": "chooseCards",
    "output": {
      "type": "chooseCardsDecision",
      "chosenCardIds": [
        "hand-0",
        "hand-1"
      ]
    }
  }
}
```

:::note
The `cards` above are cut down. On the wire they are `CardDto`s.
:::
