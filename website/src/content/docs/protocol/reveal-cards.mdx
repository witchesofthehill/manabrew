title: "revealCards"

import ProtocolType from "../../../components/ProtocolType.astro";

Sent when cards are revealed to a player and there is nothing to decide: a
Demonic Tutor reveal, a hand shown to Thoughtseize. The player acknowledges
them.

![The revealCards prompt in the Manabrew client](/protocol/reveal.webp)

## Arguments

`input.type` is `"revealCards"`. The remaining fields:

<ProtocolType slug="reveal-cards" />

## Response

```ts
type RevealCardsOutput = { type: "revealCardsAcknowledged" };
```

Acknowledge to continue.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "revealCards",
    "cards": [
      { "id": "lib-3", "identity": { "name": "Demonic Tutor" } },
      { "id": "lib-7", "identity": { "name": "Sol Ring" } }
    ],
    "zone": "library",
    "ownerPlayerId": "player-1",
    "message": "Revealed by Diabolic Revelation"
  }
}
```

Nothing to choose:

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "revealCards",
    "output": {
      "type": "revealCardsAcknowledged"
    }
  }
}
```
