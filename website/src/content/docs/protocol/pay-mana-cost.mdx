title: "payManaCost"
description: Drive interactive payment of a spell or ability's mana cost.

import ProtocolType from "../../../components/ProtocolType.astro";

Sent while the player pays a mana cost: tapping lands, activating mana
abilities, spending from the pool, delve and the like. Each step is an entry
in `actions`. The client sends one step at a time by its `id`, the engine
answers with an updated `payManaCost`, and when the cost is met the client
sends `pay`.

![The payManaCost prompt in the Manabrew client](/protocol/pay-mana.webp)

## Arguments

`input.type` is `"payManaCost"`. The remaining fields:

## Response

```ts
type PayManaCostOutput =
  | { type: "act"; actionId: string }
  | { type: "pay"; auto: boolean }
  | { type: "cancel" };
```

`act` takes one step: tap or untap a land, delve, convoke, pay life for a
Phyrexian cost. The engine answers with a new `payManaCost` showing what is
left. `actionId` must be an id from the prompt.

`pay` with `auto: true` lets the engine tap for the rest. `pay` with nothing
left to pay confirms.

`cancel` aborts the payment and the cast or activation with it.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "payManaCost",
    "cardId": "stack-3",
    "cardName": "Cryptic Command",
    "manaCost": "{1}{U}{U}{U}",
    "canConfirmFromPool": false,
    "actions": [
      {
        "id": "tap:perm-9:0",
        "type": "activateAbility",
        "cardId": "perm-9",
        "abilityIndex": 0,
        "description": "{T}: Add {U}.",
        "isManaAbility": true,
        "producedMana": [{ "color": "U", "amount": 1 }]
      }
    ]
  }
}
```

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "payManaCost",
    "output": {
      "type": "act",
      "actionId": "tap:perm-9:0"
    }
  }
}
```
