The whole deck: identity, maindeck, sideboard, extra zones, and client-side
metadata that travels with it.

<ProtocolType type="Deck" />

## DeckCard

One entry: `identity` (card and printing), a rules summary, and `uris` for
the UI.

<ProtocolType type="DeckCard" />

## DeckCardIdentity

Which card a `DeckCard` is: name, printing (`setCode`/`cardNumber`), optional
`foil`. `id` is a client-side instance id.

<ProtocolType type="DeckCardIdentity" />

## DeckLabel

A user-defined label attached to a deck.
